# Funcionalidades del sistema

Actualizado: 2026-08-18

La documentacion funcional fue reorganizada por modulo en [`docs/funcionalidades/`](funcionalidades/README.md). Ese directorio es la fuente de verdad actual para analisis funcional, validacion de alcance y lectura por procesos hospitalarios/estatales.

El catalogo monolitico anterior quedo reemplazado porque mezclaba funcionalidades historicas con estado actual y podia duplicar contenidos de capacitacion. Los manuales, capturas y documentos de entrenamiento existentes se conservan en sus ubicaciones originales y se referencian desde la documentacion modular cuando corresponde.
